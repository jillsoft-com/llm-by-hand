| ③ | 汇总：Full Batch 平均损失 | $L$（一个标量）|

## 7.1 从 Logits 到概率：Softmax

### Logits 是什么

Logits 矩阵的每一行对应一个输入位置，每一列对应词表中的一个词。某个格子的数值表示：在这一行对应的位置上，模型给这个候选词的原始得分。得分有正有负，各行数值范围也不统一，不能直接作为概率。概率必须满足两个条件：**非负**，且**同一行加和为 1**。

Softmax 同时满足这两个条件：

$$\text{这一行的概率} = \frac{e^{\text{这一行的 Logits}}}{\text{这一行所有指数值之和}}$$

### 数值稳定技巧

直接计算 $e^{\text{Logits}}$ 有溢出风险。当 Logit 很大时（如 800），$e^{800}$ 超出 float32 范围。工程上的标准做法：**每行减去该行最大值，再做指数化**：

$$\text{这一行的概率} = \frac{e^{\text{Logits}-\text{本行最大值}}}{\text{本行所有平移后指数值之和}}$$

减最大值不改变概率结果（分子分母同乘 $e^{-\max}$ 相消），但把最大的指数压到 $e^0=1$，消除溢出。

## 史海钩沉：Softmax 的命名与历史

"Softmax"这个名字可以追溯到神经网络第一次热潮时期。**1989年，英国模式识别研究者 John S. Bridle 在论文《Probabilistic Interpretation of Feedforward Classification Network Outputs》中，首次使用了"Softmax"这个名字。**

Bridle 的论文要解决一个核心问题：如何让神经网络的输出可以被解释为概率？传统的做法是"赢家通吃"——只选最大值，把其余全部置零。这种方法在数学上被称为"硬最大化"，但它有个致命缺陷：信息全丢了。模型只知道"哪个是对的"，但不知道"第二名有多接近第一名"。

Softmax 会保留 Logits 的大小顺序，同时给词表中的每个 token 分配一个概率。它不像 argmax 那样只留下最大值，因此也保留了第二名、第三名的信息。

后来，研究者们将统计物理中的"温度"概念引入 Softmax。温度参数 $T$ 控制分布的"软硬"程度：$T$ 越高，概率分布越均匀；$T$ 越低，分布越接近 one-hot。当 $T=1$ 时，就是标准的 Softmax。

**直觉**：argmax 只给出“谁最大”；Softmax 则给每个选项分配概率，最大的那个概率最高，第二名也保留信息。温度趋近于 0 时，Softmax 分布才会越来越集中到最大项。

Softmax 使用的指数归一化形式，还可以追溯到更早的统计物理。对本书来说，关键不在这段历史，而在于它完成了两步：先对 Logits 取指数，再除以所有指数之和，使一行概率之和等于 1。

## 史海钩沉：交叉熵——信息论的经典遗产

交叉熵的历史比 Softmax 更久。**1948年，克劳德·香农在《通信的数学理论》论文中首次提出了"信息熵"的概念**，这篇论文直接奠定了整个信息论的基础。

交叉熵用来衡量模型给真实答案分配的概率是否足够高。本书使用自然对数计算。

交叉熵的数学形式：

$$H(P, Q) = -\sum_i P(i) \cdot \log Q(i)$$

当 $Q$ 是模型的 Softmax 输出 $\hat{P}$、$P$ 是真实目标的 one-hot 向量 $Y$ 时，这就是 LLM 训练中使用的损失函数。20世纪的通信理论，和今天的大语言模型，用的是同一个公式。

这些历史最终落到本章的实际任务上：把 $10\times12$ 的 Logits 变成概率，再计算正确答案对应的损失。

下面，我们就从这个概率矩阵出发，计算模型在每句话上的交叉熵损失。

## 7.2 交叉熵损失

### 公式

$$\text{一行的交叉熵} = -\sum \bigl(\text{真实标签}\times\log(\text{模型概率})\bigr)$$

因为真实标签是 one-hot，只有目标词对应的位置为 1，其余为 0，所以手算时只需取目标词的概率：

$$\text{当前位置损失} = -\log(\text{目标词概率})$$

**直觉**：$\hat{P}_{t,j^*}$ 越大（模型越自信），$-\log \hat{P}$ 越小（损失越低）。如果 $\hat{P}=1$，损失为 0；如果 $\hat{P}$ 接近 0，损失趋向无穷。

### 句子1各位置的 GT 和损失

句子1的 token 序列：$[0, 3, 1, 2, 3, 8, 9, 11, 10, 10]$

每个位置的 GT（下一个 token 的索引）：

| 位置 $t$ | 当前 token | GT token |  GT 索引 $j^*$   |
|:------:|:--:|:--------:|:--------------:|
|   0    | 哈尔滨 |    东     |       3        |
|   1    | 东 |    站     |       1        |
|   2    | 站 |    在     |       2        |
|   3    | 在 |    东     |       3        |
|   4    | 东 |    边     |       8        |
|   5    | 边 |    。     |       9        |
|   6    | 。 | `<EOS>`  |       11       |
|   7    | `<EOS>` | —  |       —       |
|  8–9   | — |    —     | Loss Mask（不计入） |

有效预测位置共 7 个（$t=0$ 到 $t=6$），$t=7$ 及之后为 Loss Mask，不参与损失计算。

**手算各位置损失**：

位置 $t=0$：

$$\text{位置0损失} = -\ln(0.034238438) = 3.374406341$$

$$L_{\text{seq}}^{(1)} = \frac{1}{7}(3.374406341 + 3.244782743 + 3.448122746 + 1.956098122 + 3.182321523 + 2.717700578 + 2.335524641)$$

## 7.3 Full Batch 损失

### 为什么用 Full Batch

我们的训练方式是 Full Batch（batch size=5）：5句话全部前向传播，各自计算 $L_{\text{seq}}$，取平均后反向传播一次。

这比每句话单独反向传播（Online SGD）更稳定：梯度是5句话的平均，方向更可靠，噪声更小，一次更新覆盖全部训练数据的信息。

### 5句话的损失

对其余4句话做同样的 Softmax + 交叉熵计算（各句有效位置数均为7，句子5为6个有效位置），汇总：

| 句子 | 内容 | 有效位置数 | $L_{\text{seq}}$ |
|:--:|:--|:-----:|-----------------:|
| 句子1 | 哈尔滨 东 站 在 东 边 。 |   7   | 2.894136671 |
| 句子2 | 哈尔滨 西 站 在 西 边 。 |   7   | 3.044410954 |
| 句子3 | 哈尔滨 南 站 在 南 边 。 |   7   | 2.815754664 |
| 句子4 | 哈尔滨 北 站 在 北 边 。 |   7   | 2.898048908 |
| 句子5 | 哈尔滨 站 在 里 边 。 |   6   | 2.895936438 |

> 五句话中，句子 2（西站）的初始损失最高，句子 3（南站）最低。这并不意味着模型更“懂”南站：参数尚未训练，不同 token 组合经过随机初始化的矩阵后，恰好得到不同的目标词概率。Full Batch 的作用是让一次参数更新综合五句话的梯度；至于各句损失之后是否同步下降、是否趋于一致，要由实际训练结果判断，不能在前向传播阶段预先断言。

$$\mathbf{L = \frac{1}{5}(2.894136671 + 3.044410954 + 2.815754664 + 2.898048908 + 2.895936438) = 2.909657527}$$

这里采用“先对每句话的有效位置取平均，再对 5 句话取平均”的口径。因此句子 5 虽然只有 6 个有效预测位置，但它与其余每句话在 Full Batch 中的权重相同。

### 与随机基准比较

如果模型完全随机预测（12个词等概率，每个 $\approx 0.0833$）：

$$L_{\text{随机}} = -\log\!\left(\frac{1}{12}\right) = \ln 12 = 2.4849$$

当前损失 $2.909657527 > 2.4849$（随机基准）。

**这意味着**：这组初始参数给正确答案的概率整体偏低。随机初始化不保证初始损失一定低于随机猜测；接下来的训练会尝试把损失降下来。

> 初始损失高于随机基准并不奇怪。参数还没有训练，模型可能把较高概率分给错误答案，交叉熵就会比均匀分布时更大。最终能降到多少，要等完整训练计算完成后再填写，这里不提前猜测。

## 7.4 前向传播完整数据流回顾

本章是前向传播的终点。从第三章到第七章，数据经历了：

```
文字输入（句子1）
    ↓  第三章：Tokenization
X (10×3)              ← W_E 查表
    ↓  第四章：位置编码
X_final (10×3)        ← X + P
    ↓  第五章：Self-Attention
Z (10×3)              ← Softmax(QK^T/√d_k + Mask) · V
    ↓  第六章：残差 + LN + FFN + 输出投影
Logits (10×12)        ← LN_2 · W_O
    ↓  本章：Softmax
P̂ (10×12)             ← 每行归一化
    ↓  本章：交叉熵（Loss Mask）
Loss_t（7个值）        ← -log P̂[t, j*]
    ↓  Full Batch 平均
L = 2.909657527       ← 一个标量（各句只统计有效预测位置）
```

$L = 2.909657527$ 是一个标量，告诉我们：**当前参数下，模型在这 5 句话上的整体预测有多差**。

接下来的问题是：怎么让它变小？答案是反向传播——从 $L$ 出发，沿计算图反向推导每个参数对损失的贡献，然后按梯度方向调整参数。这是第二段（第八章起）的任务。

import numpy as np

def softmax_stable(logits):
    """数值稳定的 Softmax，按行计算"""
    shifted = logits - logits.max(axis=-1, keepdims=True)
    e = np.exp(shifted)
    return e / e.sum(axis=-1, keepdims=True)

def cross_entropy_with_mask(P_hat, gt_indices):
    """
    P_hat     : (N, V) 概率矩阵
    gt_indices: 长度 N 的列表，-1 表示 Loss Mask 位置
    返回：逐位置损失（mask 位置为 nan）和有效位置平均损失

    N = len(gt_indices)
    loss_t = np.full(N, np.nan)

            loss_t[t] = -np.log(P_hat[t, j_star])
    valid = loss_t[~np.isnan(loss_t)]
    return loss_t, valid.mean()

| 步骤 | 公式 | 本章结果 |
|:--|:--|:--:|
