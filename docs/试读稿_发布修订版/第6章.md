# 第六章：残差连接、LayerNorm、FFN 与输出投影

第五章结束时，我们得到了 Self-Attention 的输出矩阵 $Z$（$10\times3$）。每个位置的向量已经融合了 Causal Mask 允许它看到的上下文信息，也就是当前位置及之前的位置。

但一个完整的 Transformer Block 还没走完。本章要完成剩下四件事：

| 步骤 | 操作 | 核心作用 |
|:--:|:--|:--|
| ① | 残差连接 + LayerNorm | 保持信息完整，统一数值尺度 |
| ② | 前馈网络（FFN）| 引入非线性表达能力 |
| ③ | 残差连接 + LayerNorm | 同上，巩固 FFN 输出 |
| ④ | 输出投影 $W_O$ | 把内部表示映射成词表上的原始得分（Logits）|

走完这四步，模型就完成了从位置编码输入到词表 Logits 的完整前向传播，整个推理链路合龙。

## 6.1 第一个残差连接

残差连接的做法很简单：**把 Attention 的输入直接加回到输出上**。

$$R_1 = X_{final} + Z$$

**为什么需要残差连接？** 如果只把 $Z$ 送入下一层，后续层只能依赖 Attention 变换后的结果。残差连接把原始输入 $X_{final}$ 直接加回来，使这一层学习“在原表示上补充什么”，同时为反向传播保留一条更直接的梯度路径。它不是保证信息绝不丢失的“保险”，但确实显著改善了深层网络的可训练性。结构图里那条绕过 Attention 的旁路线，表示的就是这次相加。

## 史海钩沉：残差连接的历史——从ResNet到Transformer

2015 年，**何恺明（Kaiming He）等人在论文《Deep Residual Learning for Image Recognition》中提出了 ResNet**。残差连接很快成为深度网络的重要结构。

研究者发现，直接把普通网络堆得更深，并不一定更容易训练，有时训练效果反而变差。

ResNet 的解决方案极其简单：**在每一层旁边加一条"短路"，让输入可以直接跳过这一层到达输出。** 数学上就是 $y = F(x) + x$——和本章的 $R_1 = X_{final} + Z$ 是同一个公式。

**为什么这个简单操作有效？** 网络不必每次重新生成完整结果，只要学习输入还需要改变多少，也就是残差 $F(x)$。反向传播时，旁路也为梯度提供了一条更直接的路线。

**直觉**：残差连接让信息可以沿主路继续向前，同时叠加当前子层学到的新内容。Transformer 能够堆叠许多 Block，残差连接在其中起了重要作用。

从 1997 年的 LSTM 到 2015 年的 ResNet 到 2017 年的 Transformer 到今天的 GPT-4，残差连接是所有这些深度架构的共同基石。**你刚才手算的 $R_1 = X_{final} + Z$，背后是三十年的探索史。**

## 6.2 第一个 LayerNorm


先定义 $\mu$ 和 $\sigma$，再把每一行标准化。


LayerNorm 对**每一行**独立做标准化，再经过可训练的缩放 $\gamma_1$ 和平移 $\beta_1$。因为分母中加入了 $\epsilon$，归一化结果的方差会非常接近 1，而不是数学上严格等于 1：

$$
LN_1=\gamma_1\odot\frac{R_1-\mu_1}{\sqrt{\sigma_1^2+\epsilon}}+\beta_1
$$

首先计算每一行的均值：

$$
\mu_1=\frac{\sum_j R_1}{3}
$$

再计算每一行的标准差：

$$
\sigma_1=\sqrt{\frac{1}{3}\sum_j(R_1-\mu_1)^2}
$$

这里把归一化后的结果记为 $X_{norm1}$。为了防止除零错误，实际实现先给方差加上一个极小常数，再开平方：

$$
X_{norm1}
=
\frac{R_1-\mu_1}
{\sqrt{\sigma_1^2+\epsilon}}
$$

其中 $\epsilon$ 是一个很小的常数，通常取 $10^{-5}$。本书设定 $\epsilon=0.00001$。

因此，LayerNorm 可以写成：

$$
LN_1=\gamma_1\odot X_{norm1}+\beta_1
$$


> 这里使用总体标准差（除以 $N=3$），与 PyTorch 的 `LayerNorm` 实现保持一致。如果使用样本标准差（除以 $N-1$），结果会有微小差异。

初始值（第二章）：$\gamma_1 = [1, 1, 1]$，$\beta_1 = [0, 0, 0]$，所以初始时 LayerNorm 就是纯标准化，所以

$$LN_1 = \gamma_1 \odot X_{norm1} + \beta_1 = X_{norm1}$$

> **LayerNorm 与 BatchNorm 的区别**：BatchNorm 会使用 batch 中多个样本的数据；LayerNorm 则对当前 token 的特征单独归一化，不依赖 batch 大小。

## 6.3 前馈网络（FFN）

FFN 是一个两层全连接网络，**每个词独立经过 FFN**，词与词之间不互相影响（与 Attention 不同）：

```
LN_1 (10×3)
  → 第一层：× W_1(3×6) + b_1  → ReLU  → H(10×6)   ← 升维
  → 第二层：× W_2(6×3) + b_2             → F(10×3)  ← 降维
```

第一层把维度从 3 升到 6（$d_{ffn} = 2 \times d_{model}$），第二层再还原回 3。

公式表示如下：

$$FFN_{out} = FFN(LN_1) = ReLU(LN_1 \cdot W_1 + b_1) \cdot W_2 + b_2$$

这里我们令：

 $$ H_{pre} = LN_1 \cdot W_1 + b_1$$
 $$ H_1 = ReLU(H_{pre})$$

则
$$FFN_{out} = FFN(LN_1) = H_1 \cdot W_2 + b_2$$

> **为什么需要 FFN？** Self-Attention 擅长在不同位置之间聚合信息，而 FFN 对每个位置独立地做通道变换。Attention 中的 Softmax 已经带来非线性，因此它不是纯线性运算；FFN 再通过升维、ReLU 和降维增加逐位置的非线性表达能力。可以把两者的分工记成：**Attention 负责"从哪里取信息"，FFN 负责"怎样变换这些信息"**。

> **思考题**：如果把 FFN 去掉（令 $F = 0$），模型还能工作吗？
> 
> 答案：计算仍然可以运行，而且 Attention 中仍有 Softmax 非线性，所以模型不会变成纯线性系统。但它会失去 Block 中逐位置的两层非线性变换，表达能力明显受限。FFN 是 Transformer Block 的关键组成部分，不是 Attention 的重复计算。

## 6.6 Post-LN 与 Pre-LN：两种残差连接方式

前文展示的 Transformer Block 结构——先做残差连接，再做 LayerNorm——称为 **Post-LN**（Post-Layer Normalization），是 Vaswani 等人在 2017 年原始 Transformer 论文中使用的结构。

但这不是唯一的设计。另一种常见结构称为 **Pre-LN**（Pre-Layer Normalization），把 LayerNorm 放在残差连接**之前**，而不是之后。两者在现代 LLM 中都有应用，各有优劣。

### 6.6.1 两种结构的前向传播对比

以下是两种结构的计算公式对比，以第一个残差连接为例：

| | Post-LN（本书采用）| Pre-LN |
|:--|:--|:--|
| 残差 + LN 顺序 | $LN_1 = \text{LayerNorm}(X_{final} + Z)$ | $Z' = \text{Attention}(\text{LayerNorm}(X_{final}))$ |
| | | $R_1 = X_{final} + Z'$ |
| 数据流特点 | LayerNorm 在残差**之后** | LayerNorm 在 Attention/FFN **之前** |

用更直观的图示来对比（以第一个残差连接为例）：

```
Post-LN（本书）：                       Pre-LN：
                                       
  X_final ──→ Attention ──→ Z            X_final ──→ LayerNorm ──→ Attention ──→ Z'
     │                        │            │                                    │
     └────── 残差 ────────────┘            └──────────── 残差 ──────────────────┘
                │                                                  │
                ↓                                                  ↓
               R₁                                                 R₁
                │                                                  
                ↓                                                  
            LayerNorm                                              
                │                                                  
                ↓                                                  
               LN₁                                                 
```

**关键区别**：
- **Post-LN**：残差连接把 $X_{final}$ 直接加到 Attention 输出上，然后对和做 LayerNorm。
- **Pre-LN**：先对输入做 LayerNorm，再送入 Attention，然后把 Attention 输出加回到**原始** $X_{final}$ 上（不是 LN 之后的 $X_{final}$）。

两种结构在第二个残差连接（FFN 之后）也是同样的对应关系。

### 6.6.2 本书为什么选择 Post-LN

本书选择 Post-LN 作为教学版本，原因有三：

**① 教学简洁性**：Post-LN 的公式链更直观——"先加，再归一化"。一个 Block 内的数据流是线性的：$X_{final} \rightarrow Z \rightarrow R_1 \rightarrow LN_1 \rightarrow FFN \rightarrow FFN_out \rightarrow R_2 \rightarrow LN_2$。读者不需要在脑子里跳转"归一化之后又加回原来的输入"这种逻辑。

**② 公式展开更自然**：Post-LN 的 LayerNorm 输入是残差之后的和，手算时可以直接展示"这个和先算均值，再算标准差，再归一化"。Pre-LN 需要额外解释"为什么 LayerNorm 的输入和残差的输入不是同一个东西"。

**③ 与原始论文一致**：Vaswani 等人的 "Attention Is All You Need" 论文使用的是 Post-LN。作为一本从零手算 Transformer 的教程，与原始论文保持一致有助于读者对照学习。

### 6.6.3 两种结构在实际模型中的应用

| 结构 | 代表模型 | 特点 |
|:--|:--|:--|
| **Post-LN** | 原始 Transformer (2017)、BERT | 深层训练通常更依赖谨慎的初始化、学习率和 warmup |
| **Pre-LN** | GPT-2、GPT-3 及许多现代 LLM | 梯度传播通常更稳定，但工程训练中仍可能使用 warmup |

**一句话总结**：本书用 Post-LN 保持手算链路与原始 Transformer 一致；Pre-LN 常用于深层模型，并通常更容易优化。两者使用相同的基本组件，但 LayerNorm 的位置改变了前向数值和梯度路径，不能把它理解成对结果毫无影响的简单挪动。

### 6.6.4 对反向传播的影响（预告）

Post-LN 和 Pre-LN 的前向差异直接决定了反向传播时梯度的流向不同：

- **Post-LN（本书）**：后续梯度先经过 LayerNorm，再到达残差加法；在加法处，同一份上游梯度分别流向 Attention 输出和原始输入。
- **Pre-LN**：残差加法之后保留一条不经过当前子层 LayerNorm 与 Attention 的直连路径；另一条路径则经过 LayerNorm 和 Attention。两条路径回到当前 Block 的输入处汇合。

这部分细节将在第十一章反向传播中结合 Post-LN 的具体手算过程展开。

      0.56780028,  0.58898311,  0.39009522, -0.24714621, -0.50890899,  0.23303839],
    [-0.07570177, -0.47808802, -0.00610078, -0.58895711,  0.51775391, -0.30512187,
      0.20557624, -0.23816874,  0.02538426,  0.05908435, -0.39863109,  0.59398279],
    [ 0.34801855,  0.55592707,  0.49942148,  0.12383477,  0.53363339, -0.52052039,
     -0.38455464, -0.57524703, -0.22094160, -0.14081333, -0.28922314,  0.41582371],
])

gamma = np.ones(3)
beta  = np.zeros(3)

def layer_norm(x, gamma, beta, eps=1e-5):
    mu    = x.mean(axis=-1, keepdims=True)
    var   = ((x - mu) ** 2).mean(axis=-1, keepdims=True)
    return gamma * (x - mu) / np.sqrt(var + eps) + beta

# ── 第一个残差 + LayerNorm ────────────────────────────────────
R1  = X_final + Z                        # (10, 3)
LN1 = layer_norm(R1, gamma, beta)        # (10, 3)

# ── FFN ──────────────────────────────────────────────────────
H = np.maximum(0, LN1 @ W_1 + b_1)       # (10, 6) ReLU
FFN_out = H @ W_2 + b_2                        # (10, 3)

# ── 第二个残差 + LayerNorm ────────────────────────────────────
R2     = LN1 + FFN_out                          # (10, 3)
LN2    = layer_norm(R2, gamma, beta)      # (10, 3)

# ── 输出投影 ──────────────────────────────────────────────────
Logits = LN2 @ W_O                        # (10, 12)

print("LN1[0] =", np.round(LN1[0], 4))
print("H[0]   =", np.round(H[0],   4))
print("FFN_out[0] =", np.round(FFN_out[0],   4))
print("LN2[0] =", np.round(LN2[0], 4))
print("Logits[0] =", np.round(Logits[0], 4))
print("Logits.shape =", Logits.shape)     # 期望 (10, 12)

## 6.9 本章小结

本章完成了 Transformer Block 的后半部分以及输出投影：

**① 第一个残差 + LayerNorm**：$R_1 = X_{final} + Z$，保留原始信息；LayerNorm 统一每行数值尺度，输出 $LN_1$（$10\times3$）。

**② FFN**：$LN_1$ 先经 $W_1$（$3\times6$）升维并 ReLU 激活，再经 $W_2$（$6\times3$）降维，得到 $FFN_out$（$10\times3$）。每个位置独立计算，不同输入触发不同的神经元组合，提供非线性表达能力。

**③ 第二个残差 + LayerNorm**：$R_2 = LN_1 + FFN_out$，再次 LayerNorm，得到 $LN_2$（$10\times3$）。

**④ 输出投影**：$\text{Logits} = LN_2 W_O$（$10\times12$），内部3维表示映射到词表12维空间，与训练目标 $Y$ 维度对齐。

Logits 的每个元素是模型对"当前位置下一个词"的原始预测得分，尚未归一化。第七章将对 Logits 做 Softmax，计算概率分布，再与 $Y$ 对比得到交叉熵损失——前向传播的最后一步。
