## 2.1 全部参数总览

本书的极简模型共有 11 类参数，合计 **156 个可训练标量**。LayerNorm 的两组 $\gamma$ 和两组 $\beta$ 分别合并在同一行统计。

| 参数 | 符号 | 维度 | 参数量 | 物理意义 |
|:--|:--:|:--:|:--:|:--|
| Embedding 矩阵 | $W_E$ | $12\times3$ | 36 | 词表中每个 token 的初始向量坐标 |
| Query 投影矩阵 | $W_Q$ | $3\times3$ | 9 | 把输入表示投影为“我在找什么” |
| Key 投影矩阵 | $W_K$ | $3\times3$ | 9 | 把输入表示投影为“我有什么” |
| Value 投影矩阵 | $W_V$ | $3\times3$ | 9 | 把输入表示投影为“我能提供什么” |
| FFN 第一层权重 | $W_1$ | $3\times6$ | 18 | 把 3 维特征扩展到 6 维隐藏空间 |
| FFN 第一层偏置 | $b_1$ | $6$ | 6 | 神经元的激活偏移（第一层）|
| FFN 第二层权重 | $W_2$ | $6\times3$ | 18 | 把 6 维隐藏空间还原回 3 维 |
| FFN 第二层偏置 | $b_2$ | $3$ | 3 | 神经元的激活偏移（第二层）|
| 词表输出投影矩阵 | $W_O$ | $3\times12$ | 36 | 把 3 维内部表示映射到 12 维词表 logits |
| LayerNorm 缩放 | $\gamma_1,\gamma_2$ | $3+3$ | 6 | 归一化后的缩放因子（初始为 1）|
| LayerNorm 平移 | $\beta_1,\beta_2$ | $3+3$ | 6 | 归一化后的平移量（初始为 0）|
| **合计** | | | **156** | |

> **关于 $W_O$ 的记号**：本书用 $W_O$ 表示最后的词表输出投影，把 3 维内部表示变成 12 维 logits。它的参数量是 $3\times12=36$。

数据流中各参数的位置：

```
输入文字
  → W_E（查表）→ X（token embedding 矩阵）
  → + 位置编码 → X_final
  → W_Q / W_K / W_V（Attention 投影）
  → S = QK^T / √d_k → Softmax → 注意力权重 A
  → Z = A·V（加权聚合）
  → R₁ = X_final + Z → LayerNorm(γ₁, β₁) → X₁ [残差 1]
  → H = ReLU(X₁·W_1 + b_1) [FFN 隐藏层]
  → F = H·W_2 + b_2 [FFN 输出]
  → R₂ = X₁ + F → LayerNorm(γ₂, β₂) → X₂ [残差 2]
  → Logits = X₂·W_O
  → Softmax → P（概率分布）
```


为了便于理解各环节的维度变化，下面是全图参数维度关系：
```
输入文字
  → W_E 查表后                X        (10, 3)    token embedding   W_E (12,3) 查表
  → + 位置编码                X_final  (10, 3)
  → 投影为 Q, K, V            Q,K,V    (各 10, 3)
  → Attention 加权聚合        Z        (10, 3)
  → 第一次残差连接            R₁       (10, 3)    R₁ = X_final + Z
  → LayerNorm 1              X₁       (10, 3)    X₁ = LN₁(R₁)
  → FFN 升维 + 激活           H         (10, 6)    隐藏层
  → FFN 降维                  F         (10, 3)    F = H·W_2 + b_2
  → 第二次残差连接            R₂       (10, 3)    R₂ = X₁ + F
  → LayerNorm 2              X₂       (10, 3)    X₂ = LN₂(R₂)
  → 输出投影                  Logits   (10, 12)   每个位置对 12 个 token 的打分
  → Softmax                  P        (10, 12)   概率分布
```

## 2.2 初始化方法：为什么不能全用随机数

参数初始化不是随便填数字。初始化尺度不合适，可能让前向信号或反向梯度迅速放大、衰减，增加训练困难。

### 三种常用初始化方式

**① Xavier 均匀初始化**（适用于线性投影层）

$$\text{limit} = \sqrt{\frac{6}{d_{in} + d_{out}}}, \quad W \sim \text{Uniform}(-\text{limit},\ +\text{limit})$$

其中 $d_{in}$ 是输入维度，$d_{out}$ 是输出维度。

**直觉**：让信号经过线性层后保持在合适的范围。权重太大，数值容易越传越大；权重太小，信号和梯度容易越传越弱。Xavier 初始化在两者之间取一个平衡。

各参数的 limit 值：

| 参数 | $d_{in}$ | $d_{out}$ | limit |
|:--:|:--:|:--:|:--:|
| $W_Q$ | 3 | 3 | $\sqrt{6/6} = 1.00000000$ |
| $W_K$ | 3 | 3 | $\sqrt{6/6} = 1.00000000$ |
| $W_V$ | 3 | 3 | $\sqrt{6/6} = 1.00000000$ |
| $W_2$ | 6 | 3 | $\sqrt{6/9} = 0.81649658$ |
| $W_O$ | 3 | 12 | $\sqrt{6/15} = 0.63245553$ |

适用于：$W_Q$、$W_K$、$W_V$、$W_2$、$W_O$

**② Kaiming 均匀初始化**（适用于 ReLU 激活函数前的层）

$$\text{limit} = \sqrt{\frac{6}{d_{in}}}, \quad W \sim \text{Uniform}(-\text{limit},\ +\text{limit})$$

**直觉**：ReLU 会把负数变成 0，因此需要为这种变化调整初始化范围。写成均匀分布时，边界就是 $\sqrt{6/d_{in}}$。

各参数的 limit 值：

| 参数 | $d_{in}$ | limit |
|:--:|:--:|:--:|
| $W_1$ | 3 | $\sqrt{6/3} = 1.41421356$ |

适用于：$W_1$

**③ 零初始化**（适用于偏置）

$$b = \mathbf{0}$$

权重已经使用随机数初始化，因此偏置可以从 0 开始。训练时，$b_1$ 和 $b_2$ 仍会通过反向传播更新。

适用于：$b_1$、$b_2$

### 手工设计（$W_E$ 的特殊处理）

真实语言模型的 embedding 通常使用随机初始化。本书为了方便观察，给 $W_E$ 手工设计了初始值：

```
东  = [0.9,  0.1,  0.0]    西  = [−0.9, 0.1,  0.0]
南  = [0.1, −0.9,  0.0]    北  = [0.1,  0.9,  0.0]
```

原因：方位 token 在三维空间中的初始几何设计有重要的教学价值。读者可以直接观察 `东`、`西`、`南`、`北` 的坐标关系，也能在训练完成后比较这些关系如何变化。随机初始化无法提供同样直观的初始参照。

这是本章唯一采用手工数值初始化的矩阵。这样设计是为了教学，不代表真实 LLM 会预先写入方位关系。

### LayerNorm 参数

$$\gamma_1 = \gamma_2 = [1, 1, 1], \quad \beta_1 = \beta_2 = [0, 0, 0]$$

初始时 LayerNorm 不额外缩放和平移，但仍会执行标准化；训练时，$\gamma$ 和 $\beta$ 会通过梯度下降更新。

### 本章初始化方案汇总

| 参数 | 初始化方式 | 取值范围 |
|:--:|:--|:--:|
| $W_E$ | 手工设计 | 见第一章词表 |
| $W_Q$ | Xavier 均匀，$d_{in}=d_{out}=3$ | $\pm1.00000000$ |
| $W_K$ | Xavier 均匀，$d_{in}=d_{out}=3$ | $\pm1.00000000$ |
| $W_V$ | Xavier 均匀，$d_{in}=d_{out}=3$ | $\pm1.00000000$ |
| $W_1$ | Kaiming 均匀，$d_{in}=3$ | $\pm1.41421356$ |
| $b_1$ | 零初始化 | $0$ |
| $W_2$ | Xavier 均匀，$d_{in}=6,\ d_{out}=3$ | $\pm0.81649658$ |
| $b_2$ | 零初始化 | $0$ |
| $W_O$ | Xavier 均匀，$d_{in}=3,\ d_{out}=12$ | $\pm0.63245553$ |
| $\gamma_1,\gamma_2$ | 全 1 初始化 | $1$ |
| $\beta_1,\beta_2$ | 零初始化 | $0$ |


> 如果把 $W_Q$ 全部设为 0，初始的 Query 就无法区分不同输入；如果数值过大，Attention 分数又容易过分集中。因此，本书按照上面的初始化范围生成 $W_Q$、$W_K$ 和 $W_V$，并固定随机种子，保证每位读者得到相同结果。

## 史海钩沉：初始化的历史——从随机猜测到 Xavier 到 Kaiming

神经网络里的“初始化”问题看似枯燥，但它的历史恰好见证了深度学习从低谷走向爆发的全过程。

**2010 年之前：初始化方法尚未形成统一标准**

在深度学习早期，初始化往往依赖实验经验。把同一层所有权重都设为零，会让许多神经元得到相同的更新；随意使用很小或很大的随机数，又可能让信号难以穿过深层网络。

**2010 年：Xavier 初始化的诞生**

**2010 年，Glorot 和 Bengio 在论文《Understanding the Difficulty of Training Deep Feedforward Neural Networks》中，系统分析了信号在网络中逐层放大或缩小的问题。** 由此得到的 Xavier 初始化，会同时参考输入维度和输出维度。本书的 $W_Q$、$W_K$、$W_V$、$W_2$、$W_O$ 都使用这种方法。

**2015 年：Kaiming 初始化对 ReLU 的适配**

ReLU 普及以后，研究者发现还要考虑它把负数变成 0 的特点。**2015 年，何恺明等人在论文《Delving Deep into Rectifiers》中给出了适合 ReLU 的初始化方法。** 本书把这种 Kaiming 初始化用于 $W_1$，因为 $W_1$ 后面紧接 ReLU。

Xavier 和 Kaiming 最终解决的是同一个工程问题：让参数在训练开始时有一个合适的数值范围。现在，我们只要把公式算出的边界和 `seed=42` 固定下来，就能复现全书的 156 个初始参数。

## 2.3 精度说明：手算保留几位小数

本书既要方便手算，也要能用 Excel 和 Python 复核，因此区分“内部计算值”和“正文展示值”。

**正式计算精度**：本章使用 legacy NumPy 随机接口生成初值，并将初始参数统一四舍五入到 8 位小数，作为全书固定的正式参数。Excel 以双精度浮点数保存并继续计算这些数值；Python 对拍也使用 `float64`。每一步前向和反向传播都用完整的内部计算结果进入下一步，不能把正文中已经显示为 4 位或 6 位的小数重新作为后续输入。

展示精度：

| 场景 | 保留位数 | 原因 |
|:--|:--:|:--|
| 参数初始值 | 8 位小数 | 与 XLSM 参数表和 `seed=42` 生成结果逐项对应 |
| 中间过程（矩阵乘法每步）| 通常 4 位小数 | 便于手算追踪；内部计算仍保留完整精度 |
| 关键结果（损失值、概率）| 通常 6 位小数 | 便于读者与 Excel、Python 进行精细核对 |

**四舍五入说明**：正文为了便于阅读会减少小数位，但下一步计算仍使用内部完整精度。如果把正文显示的 4 位小数继续代入，误差会逐步累积。用 Excel 或代码验证时，应从 8 位初始参数出发，中间不要截断。

先看一个没有发生四舍五入误差的例子：

$$
0.9\times0.9+0.1\times0.1+0.0\times0.0
=0.81000000+0.01000000+0
=0.82000000
$$

展示为 4 位小数时就是 $0.8200$。

再看一个矩阵乘法的方向。后续章节统一使用：

$$
Q=X_{final}W_Q
$$

计算 $Q$ 中第 0 行第 0 列时，要用输入的第 0 行乘 $W_Q$ 的第 0 列。这里先用尚未加入位置编码的 `[0.5, 0.5, 0.1]` 演示：

$$
\begin{aligned}
q_{0,0}
&=0.5\times(-0.25091976)
 +0.5\times0.19731697
 +0.1\times(-0.88383278)\\
&=-0.12545988+0.098658485-0.088383278\\
&=-0.115184673\\
&\approx -0.1152 \qquad\text{（展示 4 位小数）}
\end{aligned}
$$

第 5 章会使用加入位置编码后的输入完成正式计算。这里先记住：行向量乘矩阵时，每个结果都来自输入行与权重矩阵对应列的点积。

## 2.4 三类 Mask：为什么保留完整 10 个位置

本书固定保留 10 个位置，让五句话的矩阵 shape 完全一致。较短的句子用 `<Pad>` 补齐，再用三种 Mask 分别处理。

Decoder-only 语言模型需要区分三种职责不同的 Mask：

1. **Pad Mask**：阻止查询位置读取 `<Pad>` 键；
2. **Causal Mask**：阻止当前位置读取未来 token；
3. **Loss Mask**：让没有预测目标的位置不产生 loss 和梯度。

前两种 Mask 用在 Attention 中，第三种 Mask 用在损失计算中。它们不能互相替代。

以句子 1 为例：

```text
哈尔滨 东 站 在 东 边 。 <EOS> <Pad> <Pad>
```

- **Pad Mask** 屏蔽最后两个 `<Pad>` 所在的 Key 列，避免其他位置读取填充内容。`<EOS>` 不是 Padding，不能屏蔽。
- **Causal Mask** 只允许每个位置读取自己和左边的位置，不能提前看到未来 token。
- **Loss Mask** 只保留位置 0 至 6 的预测损失。位置 6 的句号要预测 `<EOS>`；从位置 7 的 `<EOS>` 开始，后面没有真实目标，因此不再计算损失和梯度。

> Pad Mask 不要把整个 `<Pad>` 查询行都变成 $-\infty$，否则 softmax 可能得到 `NaN`。本书保留这些中间行，最后用 Loss Mask 将它们排除。

三种 Mask 的分工可以逐项对照：

| Mask | 作用对象 | 屏蔽条件 | 直接结果 |
|:--|:--|:--|:--|
| Pad Mask | Attention 的 Key 列 | $j$ 是 `<Pad>` | 有效查询不能读取 Padding |
| Causal Mask | Attention 的未来列 | $j>i$ | 当前位置不能看到未来答案 |
| Loss Mask | loss 与 logits 梯度 | 当前位置没有下一 token 目标 | 该位置不产生参数梯度 |

**为什么本书保留完整 10 个位置**：

- **固定矩阵 shape**：五句话都使用 $(10,3)$ 输入和 $(10,10)$ Attention 分数，便于逐章、逐元素核对；
- **保留 `<EOS>` 目标链**：句号预测 `<EOS>` 是有效训练任务，不能在补齐前误删句尾标记；
- **便于批量计算**：五句话可以放进同一个 batch；
- **便于复现**：所有句子的矩阵位置都能逐项对齐。

第 5 章将把这个二维 Mask 代入 $S=QK^\top/\sqrt{d_k}$，逐行计算 softmax 和 Attention 输出。

import numpy as np

# 使用 legacy RandomState 全局接口；不要改成 np.random.default_rng(42)，
# 后者使用不同的随机数算法，生成序列不会与本章相同。
np.random.seed(42)

def xavier_uniform(fan_in, fan_out):
    limit = np.sqrt(6.0 / (fan_in + fan_out))
    values = np.random.uniform(-limit, limit, (fan_in, fan_out))
    return np.round(values, 8)

def kaiming_uniform(fan_in, fan_out):
    limit = np.sqrt(6.0 / fan_in)
    values = np.random.uniform(-limit, limit, (fan_in, fan_out))
    return np.round(values, 8)

# 按顺序生成（顺序影响随机状态，不能打乱）
W_Q = xavier_uniform(3, 3)   # limit = ±1.00000000

## 2.6 本章小结

本章建立了全书的参数基础：

**① 156 个可训练标量，11 类、13 个参数数组**：从 $W_E$ 的 36 个手工设计值，到 $W_Q/W_K/W_V$ 的 Xavier 初始化，再到 $W_1$ 的 Kaiming 初始化，每类参数都有明确的初始化依据或教学理由。

**② 初始化不是随机填数**：Xavier 在前向和反向的尺度要求之间取平衡，Kaiming 针对 ReLU 调整方差，零初始化用于偏置，手工设计用于需要教学可视化的 token embedding。

**③ 精度与可验证性**：初始参数固定为 8 位小数，Excel 和 Python 使用双精度继续计算；正文根据用途展示 4 至 8 位，但展示值不回填到后续计算。完整代码可以复现全部初值、shape 和 156 参数量。

**④ 三类 Mask 各司其职**：Pad Mask 屏蔽 Padding 键列，Causal Mask 阻止读取未来 token，Loss Mask 排除没有预测目标的位置。三者共同保证固定 $N=10$ 的矩阵既便于手算，又符合 Decoder-only 下一 token 训练的因果约束。
