# 前言：揭开大模型的"概率之谜"

很多人认为大语言模型（LLM）是"智能"的，但从底层视角看，它本质上是在高维参数空间中学习一个条件概率模型。

想象你训练一个只读过五句话的孩子：他没有老师告诉他什么是语法规则，也没有人给他标注句子结构。他只能通过反复观察这些文本，逐渐调整自己的内部参数，学习哪些词之间存在稳定关系。

> "在看到‘哈尔滨’这个词之后，接下来大概率会出现哪个词？"

本书将通过一个极简模型，带你亲手拆解整个过程。从原始数据到智能预测，完整生命周期可拆解为三大核心阶段，再加一个训练与推理的应用篇：

---

## 1. 世界观的建立（预训练与统计）

- 将原始语料切分成 token，再映射为数字索引，最后查表得到向量矩阵。
- 模型通过统计发现语言规律，学习**下一个词的预测概率**。
- 例子：

  - 在极小训练集里，例如我们的五句话数据中，模型可能观察到“站”之后经常出现“在”，于是逐渐提高这个组合的概率。
  - 初始时，模型对“在”后面接哪个词的预测都差不多，训练后才会逐渐学会在“哈尔滨东站在”这个上下文中更偏向“东”。

**对应章节**：

- 第1章：词表与训练目标（one-hot 目标矩阵）
- 第2章：模型参数初始化
- 第3章：Tokenization 与输入矩阵
- 第4章：位置编码

---

## 2. 向量空间的投影（Transformer 运算）

- 核心阶段：模型通过**自注意力机制（Self-Attention）**处理词与词之间的关系。
- 文字信息在矩阵乘法中完成特征转换，最终投影到**向量表示空间**。
- 在本书的极简模型中，embedding 维度设为 3，因此可以直接观察词向量在三维空间中的变化。

**对应章节**：

- 第5章：Self-Attention 前向传播
- 第6章：Transformer Block 前向传播

---

## 3. 结果的校准（损失函数与反向传播）

- 每一次预测都会与**one-hot 目标矩阵 $Y\in\mathbb{R}^{10\times12}$** 对比：正确答案位置为1，其余为0。
- 使用**交叉熵损失函数（Cross-Entropy Loss）**衡量预测偏差。
- 通过**反向传播（Backpropagation）**更新所有 156 个参数，每一个数值都被精确计算梯度并更新。
- 5句话作为一个 Full Batch，平均损失后反向传播一次；在最多 500 次迭代中观察损失和预测结果，并按预设条件判断是否收敛。

**对应章节**：

- 第7章：Softmax、交叉熵损失函数
- 第8-13章：反向传播完整链路（从 Loss 反传到 $W_E$）

---

## 你需要什么预备知识？

本书追求**从零开始、手算到底**，但在真正动笔之前，你需要以下最基础的几项储备：

| 知识领域 | 需要掌握的程度 | 说明 |
|:---|:---|:---|
| **矩阵运算** | 会算矩阵乘法即可 | 全书最核心的计算就是矩阵乘向量（如 $\mathbf{W}\mathbf{x}$）。如果你知道 $3\times3$ 矩阵怎么乘 $3\times1$ 向量，就已经足够了。 |
| **导数与偏导数** | 理解“求导是求变化率” | 反向传播本质就是链式求导。你只要明白“对某个参数求偏导，就是看这个参数变化时损失怎么变”，后面的计算我们会一步步展开。 |
| **基础概率** | 知道概率在 $[0,1]$ 之间、和为 1 | Softmax 就是把任意数值转化为概率分布，理解这一点即可。 |
| **Python（可选）** | 能运行代码就行 | 每章附带的验证代码只是为了帮你确认“手算结果是对的”，即使完全不看代码，也不影响阅读。 |

### 不需要担心这些

- **不需要 GPU**：我们算的是 156 个参数的“玩具模型”，纸和笔就够了。
- **不需要 PyTorch/TensorFlow 经验**：全书先用手算推导，再用纯 NumPy 代码复现，没有任何框架黑盒。
- **不需要大学数学系功底**：涉及的数学不会超过高中理科+大一微积分的范畴。

### 如果你已经熟悉深度学习……

太好了！你可以把本书当作一个**“最小可运行 Transformer”**的参考实现。你会惊讶地发现：那些在大模型里被框架封装得严严实实的操作——Attention、LayerNorm、FFN、反向传播——拆解到纸面上，其实每一步都如此清晰透明。

> **一句话总结**：只要你愿意拿起笔、打开 Excel，或者跟着算，这本书就没有门槛。

## 极简模型参数说明

| 参数 | 含义 | 值 |
|:--|:--|:--|
| $V$ | 词表大小 | 12 |
| $N$ | 上下文长度 | 10 |
| $d_{model}$ | 词向量维度 | **3** |
| $d_k = d_v$ | Attention 投影维度 | 3 |
| $d_{ffn}$ | FFN 隐藏层维度 | **6** |
| $\eta$ | 学习率 | 0.1 |
| batch size | 每次更新的句数 | **5（Full Batch）** |
| 初始化方式 | 参数初始化方案 | $W_E$ 手工设计；$W_Q/W_K/W_V/W_2/W_O$ 采用 Xavier；$W_1$ 采用 Kaiming；$b_1/b_2$ 与 LayerNorm 参数按标准初始化 |
| 收敛条件 | 停止标准 | 连续 10 个 Epoch $\Delta L < 0.001$，或最多 500 个 Epoch |
| 随机种子 | 参数初始化种子 | 42 |
| 可训练参数总量 | | **156 个** |

> **为什么选 $d_{model}=3$？**
> 三维向量可以在三维空间里直接可视化。训练前后，你可以把 12 个词的坐标画成 3D 散点图，亲眼看到方位词（东/南/西/北）的几何关系如何在训练中演变——这是更高维度做不到的直觉体验。

## 词表与分词规则

本书使用 12 个 token 的极简词表，采用**极简人工设计的 token 切分规则**：

| 索引 | Token | $W_E$ 初始向量 [x, y, z] | 说明 |
|:--:|:--:|:--:|:--|
| 0 | 哈尔滨 | [0.5, 0.5, 0.1] | 地名（视为单个 token） |
| 1 | 站 | [0.6, 0.4, 0.1] | 功能词，靠近地名 |
| 2 | 在 | [0.3, 0.7, 0.1] | 介词 |
| 3 | 东 | [0.9, 0.1, 0.0] | 方位词，$x$ 轴正方向 |
| 4 | 南 | [0.1, −0.9, 0.0] | 方位词，$y$ 轴负方向 |
| 5 | 西 | [−0.9, 0.1, 0.0] | 方位词，$x$ 轴负方向 |
| 6 | 北 | [0.1, 0.9, 0.0] | 方位词，$y$ 轴正方向 |
| 7 | 里 | [0.4, 0.6, 0.1] | 方位词，内部 |
| 8 | 边 | [0.5, −0.5, 0.0] | 方位词，边缘 |
| 9 | 。 | [0.1, 0.1, 0.0] | 标点符号，近原点 |
| 10 | `<Pad>` | [0.0, 0.0, 0.0] | 填充符，补齐序列长度 |
| 11 | `<EOS>` | [1.0, 1.0, 0.1] | 结束符，标记句子末尾 |

> $W_E$ 第三维（$z$ 轴）初始值很小，主要信息在 $xy$ 平面，方便可视化，同时保留三维结构。

分词示例："哈尔滨东站在东边。"→ `哈尔滨 / 东 / 站 / 在 / 东 / 边 / 。 / <EOS> / <Pad> / <Pad> / <Pad>`

> "东站"拆为"东"+"站"，"东边"拆为"东"+"边"，以此类推。
