# 第 0 章训练结果数据

本目录保存第 0 章所述训练运行的[逐轮日志](./epoch_log.csv)、[最终参数](./final_checkpoint.npz)和[两处推理结果](./final_inference.csv)。训练使用本书的五句语料、156 个参数与 full-batch 平均损失口径；初始参数按第 2 章固定到 8 位小数，后续以 `float64` 计算，学习率为 `0.1`。

训练运行至第 500 个 epoch，损失为 `0.844642290`。预设条件是连续 10 个 epoch 的相邻损失变化均小于 `0.001`；本次运行未达到该条件，因此因轮数上限停止。两处推理的 Top-1 分别为“站”和 `<EOS>`。

`final_checkpoint.npz` 是 NumPy 数组归档。可用 `numpy.load(path, allow_pickle=False)` 读取；它包含 13 个参数数组，共 156 个有限数值。此目录记录本次运行结果，不提供第一篇后续反向传播章节的推导正文。
