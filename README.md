# 《哈尔滨教你手搓LLM：从矩阵到智能》

**作者：jillsoft**

**联系邮箱：[2836478@qq.com](mailto:2836478@qq.com)**

本书从五句关于哈尔滨车站的短句出发，用一个词表大小为 12、向量维度为 3、共有 156 个可训练参数的教学模型，带你逐步算清大语言模型的内部机制。你会看到 token 怎样变成矩阵，注意力怎样汇集信息，模型怎样得到下一个 token 的概率，以及损失和梯度怎样推动参数变化。

书中保留中间矩阵、数值代入和推导过程，并配有可复算的代码。可以先跟着小例子手算，再对照代码检查结果。

## 复算前向结果

安装 `requirements.txt` 中的依赖后，在仓库根目录运行：

```bash
python -m pip install -r requirements.txt
python docs/试读稿_发布修订版/scripts/verify_forward_ch5_ch7.py
```

脚本会逐句计算五句训练语料的初始损失，并核对 Full Batch 平均损失。脚本只复算本次公开章节中的前向计算。
